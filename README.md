# 🥜 견과 한 줌 — 견과류 객체인식 & 칼로리 안내

사진 한 장으로 **여러 종류가 섞인 견과류를 하나하나 인식**하고, 종류별 개수·칼로리·효능·주의사항을 알려주는 앱입니다.
어르신을 주 대상으로 하지만 운동하는 사람과 일반 사용자도 쉽게 쓸 수 있도록 **사용자 유형별 모드**를 제공합니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 다중 객체 인식 | 한 사진 속 여러 견과류를 각각 박스로 표시하고 종류별로 개수를 셈 |
| 칼로리·영양 계산 | 개당 평균 무게 × 개수 → 무게, kcal, 단백질/지방/탄수화물 추정 |
| 하루 권장량 비교 | 한 줌(30g) 대비 몇 %인지 막대로 표시, 초과 시 경고 |
| 효능·주의사항 | 견과류별 좋은 점과 주의점 (예: 은행 하루 10알 이하, 브라질너트 1~2알) |
| 사용자 모드 | 👵 어르신(큰 글씨, 천천히 읽어주기, 안전 안내) / 🏃 운동(단백질·탄단지) / 🙂 일반 |
| 수동 보정 | 인식이 틀리면 －/＋ 버튼으로 개수 수정, 빠진 견과류 추가 → 즉시 재계산 |
| 음성 안내 | 🔊 버튼으로 결과를 한국어 음성으로 읽어줌 (브라우저 내장 TTS) |
| 접근성 | 큰 터치 영역(48px 이상), 글자 크기 키우기, 고대비·다크모드 지원 |

지원 견과류(12종): 아몬드, 호두, 캐슈넛, 피스타치오, 땅콩, 마카다미아, 피칸, 헤이즐넛, 브라질너트, 잣, 밤, 은행
→ `backend/app/data/nuts.json` 에 항목을 추가하면 인식 대상과 영양 정보가 함께 늘어납니다.

## 구조

```
backend/
  app/main.py          FastAPI 서버 (/api/analyze, /api/nuts), 프론트엔드 정적 파일 제공
  app/detector.py      인식기: Claude 비전(기본) / YOLO(직접 학습 모델) / 데모
  app/nutrition.py     영양 DB 로딩, 칼로리 계산
  app/data/nuts.json   견과류 영양·효능·주의사항 데이터
  tests/               API 테스트
frontend/              모바일 웹앱(PWA) — 카메라 촬영, 박스 표시, 결과 카드
```

## 실행

```bash
cd backend
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...        # 없으면 데모 모드(예시 결과)로 실행됩니다
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

휴대폰 브라우저에서 `http://<서버주소>:8000` 접속 → 📷 사진 찍기. (휴대폰 카메라 사용에는 HTTPS 배포를 권장합니다.)
홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

테스트: `cd backend && pytest`

### 인식기 선택 (`NUT_DETECTOR`)

| 값 | 설명 |
| --- | --- |
| `claude` | Claude 비전 모델이 견과류마다 종류·박스를 JSON 구조화 출력으로 반환 (키가 있으면 기본값). 모델은 `NUT_CLAUDE_MODEL` 로 변경 가능 |
| `yolo` | 직접 학습한 YOLO 가중치 사용 (`NUT_YOLO_WEIGHTS=best.pt`, `pip install ultralytics pillow`). 클래스 이름은 `nuts.json` 의 id 와 동일하게 |
| `demo` | 고정된 예시 결과 (UI 확인용) |

## 다음 단계 제안

1. **데이터 수집 → 전용 모델 학습**: Claude 인식 결과를 사용자가 수정한 데이터로 라벨을 모아 YOLO를 학습하면, 비용 없이 빠르게(오프라인·온디바이스까지) 인식할 수 있습니다.
2. **무게 정확도 향상**: 동전·카드 같은 기준 물체로 크기를 보정하거나, 박스 면적으로 개별 무게를 추정.
3. **가공 여부 인식**: 소금/설탕 코팅, 껍질 유무에 따라 나트륨·칼로리 보정.
4. **기록·가족 공유**: 하루 섭취 기록, 보호자에게 요약 알림.
5. **네이티브 앱**: 현재 PWA를 Flutter/React Native로 감싸 앱스토어 배포.
