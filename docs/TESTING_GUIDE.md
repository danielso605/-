GitHub 나 프로그래밍 환경을 몰라도 따라 할 수 있게 정리했습니다. **웹 브라우저만** 있으면 됩니다.

| 단계 | 하는 일 | 걸리는 시간 | 비용 |
| --- | --- | --- | --- |

## 1단계: Colab 으로 오늘 바로 테스트

Colab 은 구글이 제공하는 무료 '코드 실행 공간'입니다. 아무것도 설치할 필요가 없어요.

1. **https://colab.research.google.com** 에 구글 계정으로 로그인합니다.
2. 처음 뜨는 창(또는 메뉴 `파일 → 노트북 열기`)에서 **GitHub** 탭을 누릅니다.
3. 검색칸에 `danielso605/-` 를 입력하고 엔터.
4. **브랜치** 목록에서 `claude/nut-recognition-calorie-app-y8lu3b` 를 고릅니다.
   (PR 을 main 에 합친 뒤라면 `main` 그대로 두면 됩니다)
5. 목록에서 **`colab/app_test.ipynb`** 를 누릅니다.
6. 열린 노트북에서 위에서부터 셀 왼쪽 **▶** 를 하나씩 누릅니다.
   - ① 앱 설치 → ② `best.pt` 올리기 (파일 선택 버튼) → ③ (선택) 휴대폰 내 인식 모델 → ④ 서버 켜기 → ⑤ 주소·QR 코드
   - '경고: 이 노트북은 Google 에서 작성하지 않았습니다' 가 뜨면 **무시하고 실행** 을 누르세요.
7. ⑤ 에서 나온 **QR 코드를 휴대폰 카메라로 찍으면** 인식 테스트 화면이 열립니다.
8. 사진을 찍고 → 틀린 박스를 고치고 → **정확도 측정용으로 저장** → `/report` 에서 정확도 그래프 확인.
9. 끝내기 전에 ⑥ 셀로 **저장한 사진을 zip 으로 백업**하세요. Colab 을 닫으면 사라집니다.

> ② 셀에서 "⚠️ 앱이 모르는 이름" 이 나오면 그 종류는 칼로리 계산에서 빠집니다. 출력된 이름을 알려 주시면 맞춰 드립니다.

## 2단계: 고정 주소로 올리기 (Hugging Face Spaces)

Colab 주소는 끌 때마다 바뀝니다. 계속 쓰려면 무료 서버에 올립니다.

1. **https://huggingface.co** 에 가입합니다.
2. 오른쪽 위 프로필 → **New Space**
   - Space name: 예) `nut-app`
   - **SDK: Docker** → **Blank** 선택
   - Hardware: **CPU basic (무료)**
   - Visibility: 처음엔 **Private** 권장 (나만 접속)
3. 만들어진 Space 의 **Files** 탭 → **Add file → Upload files** 로 아래 파일을 올립니다.
   - 이 저장소의 `deploy/huggingface/Dockerfile`
   - 이 저장소의 `deploy/huggingface/README.md` (Space 에 원래 있던 README 를 덮어써야 합니다)
   - 내 **`best.pt`** (이름 그대로 올려도 됩니다)
   - (선택) `nuts.onnx` — 휴대폰 안에서 인식용, 1단계 ③ 셀에서 만든 파일
   
   GitHub 에서 파일 받는 법: 파일을 누르고 오른쪽 위 **⬇ (Download raw file)** 버튼.
4. 올리면 자동으로 빌드가 시작됩니다 (5~15분). **App** 탭에 앱 화면이 나오면 성공.
5. 주소는 `https://<아이디>-nut-app.hf.space` 형태입니다. 휴대폰에서 열고:
   - **안드로이드(크롬):** 메뉴 ⋮ → **홈 화면에 추가 / 앱 설치**
   - **아이폰(사파리):** 공유 버튼 → **홈 화면에 추가**
   → 바탕화면에 🥜 아이콘이 생기고 앱처럼 전체 화면으로 열립니다.

알아 둘 점
- 무료 Space 는 한동안 안 쓰면 잠들고, 다시 열 때 1~2분 걸립니다.
- 서버가 다시 시작되면 **저장한 테스트 사진이 초기화**됩니다. 정확도 측정용 사진은 1단계 Colab 에서 모아 백업하는 걸 권장합니다.
- Private Space 는 휴대폰에서도 Hugging Face 로그인이 필요합니다.
- 이 Dockerfile 은 작업 환경 제약으로 실제 빌드 테스트를 하지 못했습니다. 빌드 오류가 나면 **Logs** 탭 내용을 알려 주세요.

## 3단계: 앱스토어 앱으로 만들기

2단계의 주소를 그대로 '앱 껍데기'에 넣어 스토어에 올리는 방식이 가장 쉽습니다. (이미 아이콘·오프라인 기능 등 필요한 준비는 해 두었습니다)

1. **https://www.pwabuilder.com** 에 2단계 주소를 입력합니다. (Space 를 **Public** 으로 바꿔야 합니다)
2. 점수 확인 후 **Package for stores**
   - **Android:** 생성된 패키지를 **Google Play Console**(개발자 등록 $25, 1회) 에 올립니다.
   - **iOS:** Apple Developer($99/년) + Mac 의 Xcode 가 필요합니다.
3. 공개 전에 꼭 할 일
   - `/label`, `/report` 와 사진 저장 기능에 **관리자 로그인** 붙이기 (지금은 주소를 알면 누구나 접근 가능)
   - 개인정보 처리방침 페이지 (사진을 서버로 보내므로 스토어 심사에 필요)

이 단계가 되면 말씀해 주세요. 로그인 기능과 개인정보 처리방침 초안을 만들어 드립니다.
